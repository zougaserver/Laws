---
title: "LIVRE IX - Procédures simplifiées"
---

## Article 40 — Transaction pénale

Pour les délits majeur, le Procureur peut proposer :

* une amende immédiate ;
* un remboursement ;
* des travaux d’intérêt général.

L’acceptation met fin aux poursuites.

## Article 41 — Comparution immédiate

En cas de flagrant délit et de preuves suffisantes, le prévenu peut être jugé immédiatement.

## Article 42 — Ordonnance simplifiée

Le juge peut rendre une décision simplifiée sans audience pour :

* les délits majeurs ;
* les amendes simples ;
* les troubles légers à l’ordre public.

Le prévenu conserve le droit de demander un procès classique.
