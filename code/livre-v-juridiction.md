title: "LIVRE V - Juridiction"
---

## Article 22 — Tribunal local

Le Tribunal local juge :

* les contraventions ;
* les délits mineurs ;
* les litiges simples.

## Article 23 — Cour criminelle

La Cour criminelle juge les crimes graves, notamment :

* homicide ;
* enlèvement ;
* corruption ;
* trahison ;
* grand banditisme.

## Article 24 — Composition de la Cour

La Cour siège avec :

* un juge ;
* un procureur ;
* et, pour les crimes majeurs, un jury populaire.

## Article 25 — Publicité des audiences

Les audiences sont publiques sauf :

* risque grave pour l’ordre public ;
* protection d’un mineur ;
* nécessité de protéger un témoin ;
* décision du juge.
