# LIVRE X - Dispositions finales

## Article 43 — Application territoriale

Le présent Code s’applique à toute personne présente sur le territoire du Comté de West Elizabeth.

## Article 44 — Entrée en vigueur

Le présent Code entre en vigueur dès sa promulgation par les autorités du Comté.

## Article 45 — Autorité du Code

Toute procédure pénale conduite dans le Comté doit respecter les dispositions du présent Code.
